这个文件夹用于沉淀“内容创作与流量运营的方法论学习资料”。

## 使用边界

只放：

- 经典传播理论。
- 用户心理机制。
- 爆款内容结构。
- 优秀案例拆解。
- 平台行为信号分析。
- 内容运营方法论。

不放：

- 个人账号定位建议。
- 个人选题建议。
- “你应该做什么”的判断。
- 临时口播稿或发布稿。
