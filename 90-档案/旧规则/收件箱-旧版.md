## 使用方式

- **手机**：豆包输入法 + iOS Shortcut 追加到这里（见 `输入捕获方案.md`）
- **桌面批量**：从小红书 / 即刻 / 公众号 / 浏览器收藏夹把一大堆内容复制粘贴过来。**不用格式化**。Claude 能帮你清洗。

## 批量导入的工作方式

告诉 Claude："我在收件箱贴了 N 条，请帮我：
1. 识别每条是什么（URL / 文字 / 图片）
2. 判断来源（小红书 / 即刻 / ...）
3. 每条给一个候选文件名
4. 先建素材库文件、frontmatter 填来源类型 / 来源链接 / 摘要 / 创建时间；`为何保存`和`可用角度`留空我来补
5. 清洗后的内容从「待清洗」移到「已清洗日志」一行备注"
