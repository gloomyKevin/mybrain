# 旧规则说明

> 这里用于解释旧规则如何被看待。旧规则保留历史价值，但不默认指挥当前系统。

## 当前判断

早期 MyBrain 有多份类似“宪法”“SOP”“硬约束”的文件。这些文件记录了当时的阶段目标、风险意识和 AI 协作方式，但其中一部分已经过期。

当前使用时，先看 `00-系统/当前协议.md`。旧规则只作为历史背景。

## 旧规则怎么用

- 可以作为理解过去决策的背景。
- 不应直接当作当前硬约束。
- 如果旧规则和当前系统地图冲突，以当前系统地图为准。

## 常见旧规则类型

- 过期时间约束：例如某个已经过去的发布日期。
- 阶段性限制：例如 Month 1-2 不加工具。
- 早期目录结构：例如旧版唯一收件箱。
- 触发词式 SOP：可以回收思想，但不必机械执行。

## 处理原则

旧东西不急着删。明显过期的放这里，仍可能指导当前思考的放到 `00-系统/当前思考/`。
