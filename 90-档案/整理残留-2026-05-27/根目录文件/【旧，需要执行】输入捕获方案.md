# 输入捕获方案（精简版）

## 当前唯一落地：豆包 + iOS Shortcut → `收件箱.md`

**设置（一次）：**

1. Obsidian 装 `Advanced URI` 社区插件
2. iOS 快捷指令新建 `捕获到收件箱`：
   - 动作 1：`要求输入`（文本）
   - 动作 2：`打开 URL`：
     ```
     obsidian://advanced-uri?vault=mybrain&filepath=收件箱.md&mode=append&data=<时间戳> <输入>
     ```
3. 快捷指令加到主屏幕 + 绑 Back Tap（设置 → 辅助功能 → 轻点背面 → 双击）

**日常用法：** 双击手机背 → 豆包打字或语音 → 回车。5 秒内完成，Obsidian 都不用打开。

Android 可用 Tasker / Obsidian 的 append intent 实现同款。

## 其他场景先不做

Month 1-2 约束（`OPC 规划.md` §二）：**不加新工具**。

截图、URL 分享、播客、浏览器剪藏等，**当前全部走"手动粘贴进 `收件箱.md`"**。

触发加新捕获方式的判据：**某个场景每天要发生 5 次以上，手动粘贴变成明显摩擦**。不卡不加。
