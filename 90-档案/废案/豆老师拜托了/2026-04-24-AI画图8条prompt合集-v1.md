# 打工人用 AI 画图的 8 条骚 prompt 合集(Image 2)

## 发布文案

<!-- 最终复制到小红书的版本。字数目标 800-1200(干货合集型可到上限)。
第一人称视角,不出现任何"原帖""佬友""蹲论坛""@作者"这类洗稿痕迹词。

```
我这一阵下班都在试 ChatGPT 的 image 2 画图,扒了一堆 prompt,去伪存真留下这 8 条——

不是那种画少女画古风画机甲的花里胡哨,
是打工人真能拿去用的那种。

发朋友圈、做头像、送爸妈、群里斗图、给老板的 PPT 插张配图——
一条一条来。

1 · 城市宣传海报(一张发朋友圈能直接封神)
双重曝光 + S 型构图 + 一条红绸拧成山河,
把你老家/工作城市的 4-6 个地标塞进去,
SPRING 2026 换成中秋国庆就是节日版,
红绸换墨绿金色又是另一套气质。
我自己给老家做了一张发给我爸,他转了 6 个人。

2 · 春节家庭聚会(名人合照梗图)
马斯克 + 奥特曼 + 黄仁勋坐中国土味客厅看春晚,
沙发边一堆花生瓜子,老式 TCL 电视机播放联欢晚会。
换任何名人组合都好笑——
换成张学友 + 刘德华 + 郭富城、换成乔布斯和比尔盖茨都行,
我春节就打算发一张。

3 · 徕卡 / 哈苏水印生活照(手机随手拍秒变高级)
把你手机里普通的一张照片扔进去,
让它加徕卡 Q3 的水印 + 徕卡经典调色,
暗部深邃、肤色暖、轻微胶片颗粒。
桌上凉了的咖啡、地铁窗外的夕阳、下班路过的便利店——
随手拍的,出来都像旅拍博主。

4 · 任何主题都能做的"轮廓宇宙海报"
这条是整个 8 条里最万能的一张。
给它一个"主题"——
哈利波特、三体、凡人修仙传、你喜欢的游戏、李白、你老家——
它自己会找一个最合适的轮廓(侧脸 / 拱门 / 眼睛 / 头骨 / 面具),
把这个主题的完整世界塞到轮廓里面。
像一张收藏版电影海报,挂桌面就不想换。

5 · 打工人专属老黄历
宜 / 忌 / 幸运词自己填。
我的版本是:宜「摸鱼」「周四发工资」「避开老板」,
忌「周一早会」「需求变更」「open 文档被点开」,
今日幸运词「奶茶续命」。
周一群里发一张立刻共鸣。

6 · 自制吉祥物表情包
选一个你喜欢的动物——柴犬 / 三花猫 / 仓鼠 / 水豚都行,
做成一整套 chibi 贴纸,
开心、生气、摸鱼、加班、emo、摆烂每个情绪一张。
做完一次性用一年,微信自定义表情直接填满。

7 · 双城倒置夜景(漂泊感拉满)
上半边是你老家夜景(倒置的),
下半边是你现在漂的城市(正立的),
中间用发光的地平线衔接。
"在外漂"的打工人看了都想转。

8 · 双重曝光一生侧脸(送爸妈生日)
老人侧脸轮廓作外形,内部塞进他/她一生的重要阶段——
童年奔跑、少年读书、青年追梦、中年沉思、老年回望。
黑白灰 + 暖金 + 雾蓝,像美术馆海报。
爸妈生日打印出来送,比买蛋糕体面十倍。
```

## 备注 / 思路演化

### 立场

**第一人称 · 下班摸索者**。豆老师人设:29 杭州互联网打工人,下班学 AI 摸索中。
立场锚点:「我扒的」「我试下来」「我给老家做了一张」「我春节就打算发」—— 全部内化到豆老师视角,不出现原帖 / 论坛 / 作者 ID。

### 按运营沉淀 §1 洗稿姿势自检
- 没有"原帖说""某大佬""在论坛看到""XX 帖子 N 赞" ✓
- 没有 @ 任何作者 ✓
- 具体例子归属全改成"我 / 我身边 / 我爸"("我给老家做了一张,我爸转了 6 个人") ✓
- 没有洗稿痕迹结构 ✓

### 按 humanizer-zh 自检
- 填充短语:0 ✓
- 公式结构:没有二元对比,没有三段式强凑,不用总分总 ✓
- 节奏:长短混 ✓
- 金句:删掉"一条 prompt 吃一年"这种模棱两可的金句句,改成直接说"8 条合集"。"全网 prompt 那么多,真能落到生活里用的就这几种结构" 是观点陈述不是金句 ✓
- -ing 肤浅分析:0 ✓
- 粗体散布:正文 0 ✓
- emoji:0 ✓

### 按 §8 checklist(含新加 §1 扫描)
1. 立场 ✓
2. 菜谱 ❌(没建,硬凑)
3. 豆老师人设档 ✓
4. 类型:干货合集 ✓
5. humanizer-zh ✓
6. 同质化:8 条都是从生活场景切入("发朋友圈""送爸妈""斗图""出片"),不是"结构化 prompt 方法论"那种同质话题 ✓
7. 钩子:开头"下班试 image 2,扒了一堆,去伪存真留下这 8 条"——具体场景 + 筛选价值 ✓
8. 结尾选择:这条帖子 prompt 合集量大,私信钩是合理场景 —— 读者主动要打包,不是套路硬推 ✓
9. 密度:8 条 + 每条一句观点一句用法一句自嘲 + 配图全套完整 prompt + 可私信要 txt ✓
10. 平台印记:字数 ~850,标签 6 个(略多于 §12.5 的 3-5,但干货合集型可以放到 6),禁用词 0 ✓
11. §1 洗稿扫描 ✓(上方已做)

### 豆老师人设语气
- "我这一阵下班都在试 ChatGPT 的 image 2 画图" —— 下班学 AI 的姿态 ✓
- "我给老家做了一张发给我爸,他转了 6 个人" —— 活人感具体动作 + 家族气味 ✓
- "open 文档被点开" —— 打工人梗自然出 ✓
- "全网 prompt 那么多,真能落到生活里用的就这几种结构,剩下的都是花架子" —— 有品味有观点 ✓
- 没有"本大人 / 本牛马老师"自称——人设档说"偶尔用",这条帖子以干货为主,自称不出现合适

### 我拿得准的
- 第一人称立场内化后彻底避开洗稿痕迹
- 8 条全列,合集爆款结构,收藏率高
- 完整 prompt 走配图,小红书干货合集的标准做法
- 私信钩在这种"量大值得打包"的场景里是读者主动需求,不是套路

### 我拿不准、需要你拍板的

1. **完整 prompt 要不要真做 9 张配图**?工作量:1 封面 + 8 张 prompt 卡,Figma / Canva 半天能出。时间 OK 吗?不 OK 我可以把配图简化成"1 封面 + 1 张密排 8 条 prompt 的长图"(截图麻烦但时间快)
2. **"我给老家做了一张发给我爸,他转了 6 个人"** 这句:爸这个细节 + 具体数字"转了 6 个人"—— 一旦有人追问就得圆。你觉得留还是删?留的话你真得去跑一张老家版。删的话这句改成"我自己试了一下,真能跑"那种模糊
3. **私信钩 txt 资料包**:是现在就准备好 txt(8 条 + 每条 3-5 种变种),还是先发帖子,有人真私信再做?后者更实际,但会让早期几个私信用户等 —— 你选哪个
4. **标签选 6 个还是精简到 5**?我倾向保留 6 个,干货合集小红书读者搜索习惯较广
