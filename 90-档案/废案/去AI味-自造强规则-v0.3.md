# 去 AI 味 · 自造强规则(废弃存档)

## 为什么废弃

2026-04-24 与用户沟通确认:这几节在豆老师账号文案生产里造成**反效果**。

具体问题:

- §3.2 的 26 条黑名单和 §3.3 的"刻意人味动作"被 Claude 机械叠加,结果从 AI 味 1.0(公式化升华)换成 AI 味 2.0(刻意破相 / 刻意灵光 / 刻意生活动作)。形式变,底没变,都是"规则堆"
- 规则列得越多,写作越刻意,越像"在表演真人"
- humanizer-zh skill 覆盖了这里 90% 的禁止清单,来源更系统(维基 WikiProject AI Cleanup),本身更克制,不堆"人味动作"式的正向指导

所以挪出来。本章完整保留在废案备查,写作时用 humanizer-zh。

## §3.2 AI 签名黑名单(原文,已废弃)

**结构类**:
1. 结尾公式化问句:「你呢?评论区聊聊 👇」「你中招了吗?」
2. 每段一个升华金句(不停总结的冲动)
3. 排比句过度整齐(「不是 X,是 Y」反复用)
4. 否定式排比:"不仅仅是 A,更是 B" / "这不只是 X,而是 Y"——比 #3 更典型的 AI tell
5. 爱用对比表(AI 最爱结构化)
6. 整齐的 N 要点列举(刻意排版美学)
7. 三段式法则强凑:把想法强行拆成三组以显得"全面"(「演讲、小组讨论和社交机会」式)——宁可用两项或四项
8. 标题问句 + 答案悬念式("到底要不要 X?答案可能颠覆你认知")
9. 总分总 / 并列式模板结构
10. 内联标题+冒号列表:`**用户体验:** xxx` / `**性能:** xxx` 这种格式,AI 最爱用来"看起来有条理"
11. 粗体密集散布(每段都有 2-3 处粗体强调)
12. 虚假范围 "从 X 到 Y"(X 和 Y 并不在同一维度上——"从大爆炸到暗物质")
13. 提纲式"挑战与未来展望"收尾段("尽管面临…挑战,凭借…继续蓬勃发展")

**用词类**:
14. 判断词滥用:真正的 / 核心是 / 本质上 / 说白了
15. 机械连接词:首先 / 其次 / 最后 / 总之 / 综上所述 / 应该注意的是
16. AI 高频词:值得注意的是 / 毫无疑问 / 一般来说 / 换句话说
17. 过渡词口癖:"其实我想说的是""换个角度看"
18. 商业黑话:赋能 / 闭环 / 抓手 / 对齐 / 深耕
19. 开场拐棍:说实话 / 不得不说 / 有一说一
20. -ing / "着" 结尾肤浅分析:句末挂"强调着…""反映着…""体现着…""为…做出贡献""确保…"——AI 用来注水深度
21. 模糊归因:"行业报告显示""专家认为""观察者指出""一些批评者"——不给具体来源。要么挂真名真出处,要么删
22. 系动词回避:用"作为 / 代表 / 标志着 / 充当"替代"是",用"拥有 / 设有 / 提供"替代"有"——AI 嫌"是"太短
23. 同义词循环:同一个对象在段内被称为"主人公/主要角色/中心人物/英雄" 轮流换——真人会直接重复或用代词

**情绪类 / 交流类**:
24. 语气始终"稳定成熟"——不翻车 / 不自嘲 / 不吐槽
25. emoji 套路化(👇✨🔥💯)
26. 协作交流痕迹:"希望这对您有帮助""当然!""一定!""您说得完全正确!"——聊天机器人残留,直接删

## §3.3 人味动作(原文,已废弃)

**结构破相**:
- 段落长度故意不均匀(有的一句话就结束)
- 偶尔半句话 / 破折号 / 省略收尾
- 打破总分总——可以不收束
- 陈述偶尔改反问/设问(别滥用)

**细节具体化**:
- 文件名带情绪(`临时思路-真的吗.md`)
- 具体时长("半个周末""快一年""差点原地关机")
- 具体挫败("清理花了我半个周末")
- 具象比喻但避免老套

**语气层**:
- 允许显得翻车过 / 自嘲
- 吐槽但克制(不多)
- 论点模糊化("我觉得""大概""或许""在多数情况下")——像个人观点不像绝对真理
- 冗余插入语:「说起来」「话说回来」「实际上」「反正」

**句式层**:
- 被动 → 主动
- 长短句交错
- 短句优先

**为什么废弃**:这一节是 AI 味 2.0 的发源地。"刻意做这些"="刻意表演真人",反而显假。真人有这些特征是**因为底色如此**,不是刻意堆。出路在 §13 菜谱,不在这里堆动作。

## §3.4 机械词替换对照(原文,已废弃)

- 值得注意的是 → 删掉 / 或「注意」
- 毫无疑问 → 删掉 / 或「这个应该没人会吵」
- 综上所述 → 删(打破总结冲动)
- 首先 / 其次 / 最后 → 改叙事语序 / 用"先…然后…后来"
- 换句话说 → 直接说 / 或「就是」
- 一般来说 → 「大多时候」/ 删
- 真正的 X 是 Y → 「X 其实是 Y」
- 总之 / 综上所述 → 删

**替代**:humanizer-zh §7 "高频 AI 词汇"已覆盖这组对照。
