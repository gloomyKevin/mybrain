# 写 prompt 不是许愿（image 2 高赞 prompt 拆解）

## 发布文案

<!-- 最终复制到小红书的版本。目标字数 500-700。 -->

昨晚蹲一个 image 2 生图比赛蹲到两点。

278 楼我一条条翻，把每条 prompt 贴出来看结构。翻到第 30 楼的时候我突然 yue 了——**那些拿几十上百赞的 prompt，写法全是一个样：不像写文案，像写 TODO list。**

国潮海报、游戏封面、storyboard、博物馆信息图、程序员老黄历——完全不同的风格，骨架却是同一套。

五个槽位，一个不能少：

**① 主体**：画什么——对象 + 场景 + 动作。不是"一个漂亮的女孩"，是"身穿中国传统服饰的微缩人物，正在挥舞红色丝绸舞带"。

**② 构图**：怎么排——视角 / 分区 / 留白比例。高赞里最狠的是 "上大下小的层级结构：上半部分是巨大剪影主体，中下部是完整人物"。画面还没画，分镜已经定好了。

**③ 风格**：像谁——"国家博物馆展板、历史服饰图鉴、文博专题信息图，**而不是**普通海报、古风写真、电商详情页"。注意那个"而不是"——直接给反例，比正例还管用。

**④ 光影材质**：质地——"米白、绢纸白、浅茶色纸张质感"、"水墨晕染和虚化破碎"、"云雾环绕，仙气缥缈"。

**⑤ 输出规格**：规格——"9:16"、"文字清晰完整"、"整体克制、高级、可收藏"。

最极端一条是博物馆图鉴那帖——直接 key-value 格式写："顶部：主标题 + 副标题 / 左侧：结构拆解区 / 右上：材质区 / 右中：纹样区 / 底部：流程图"。**到这一步已经不是 prompt，是一份产品 spec**。

反过来看我过去一年写的东西：

"帮我生成一个海报""帮我写个登录页""帮我优化这段代码"——全是许愿。把 why 糊在脑子里，让模型猜 what 和 how。然后每次结果不对就怪模型蠢。

**MJ 这样，Claude Code 也这样**。你写给 AI 的那段话，本质是一份任务说明书，不是一条心愿。槽位缺得越多，它越自由发挥，你就越容易骂街。

五条原 prompt 我整理在一个文件里，附我拆的槽位模板可以直接套——小红书贴不下，想要的评论区冒个泡我私发。

## 备注 / 思路演化

### 立场档位声明（§0）
**当前：观察者/策展人档**。用户没实操 Image 2，不能自称"实战者"。"昨晚蹲了一个比赛蹲到两点"是真实立场（用户确实 clip 了这帖）。

升档到"实战者"需要：用户真跑 1-2 条 prompt，配文加一句"我拿 #31 那条 prompt 自己跑了一下，xxx"。

### §8 Checklist 自检
1. 立场来源：✅ 观察者立场，用户真实 clip 了帖子。但读者可能问"你自己用过吗"——得接受这个软肋
2. 个人底味 Skill：❌ 无（当前档无 `写作风格-菜谱.md`，硬凑）
3. 类型判定：干货 + 案例混合型，按 §2 保留密度不扁平化 ✓
4. AI 签名扫描 §3.2（26 条）：
   - #4 否定式排比：初稿有"不是写文案，像写 TODO list"——这是刻意的反转修辞一次用，没重复用，可接受
   - #18 商业黑话："闭环/赋能/深耕" 零命中 ✓
   - #20 -ing 肤浅分析："呈现着""象征着"零命中 ✓
   - #26 协作交流痕迹："希望对您有帮助"零命中 ✓
   - 其余抽查无命中
5. 同质化自检：10 个 AI 用同素材会写成一样吗？——大概率不会，"槽位 5 条 + 代码风任务书"这个落脚点是论据筛选后的判断，不是素材本身 ✓
6. 钩子强度：开头具体（蹲到两点、第 30 楼、278 楼）✓；结尾不是"评论区聊聊"✓
7. 密度兑现：5 个槽位 + 每个配具体引用 + 一份可套模板 ✓
8. 人味保留：段落长度不均（第一句就结尾、中段有短句插入）✓；吐槽"然后每次结果不对就怪模型蠢"一处 ✓；论点模糊化："大概率"等词保持观点而非真理 ⚠️ 较少，可加
9. 平台印记 §12：
   - 字数 ~580 字 ✓（小红书 400-1000 带区间）
   - 平台禁用词（绝绝子/家人们）零命中 ✓
   - 标签 5 个 ✓ 不堆砌
   - 结尾私信钩子 ✓
10. 自评块 ✓（本节）

### 我拿得准的
- 5 层槽位的论点成立，5 条案例支撑足够
- "写 prompt = 写任务说明书"落脚回 vibe coder 成立
- 字数、标签、结尾符合 §12

### 我拿不准、需要你拍板的
1. **立场档位**：走观察者够不够稳？要不要你今晚花 30 分钟跑 1 条 prompt 升到实战者档？
2. **原图使用**：用原图标注作者 vs 全自制示意图，哪个接受？
3. **开头"yue"字**：是想要的小红书语感还是显油腻？我保留着你定
4. **博物馆图鉴 #31**：这条本身是"佬友转载"非比赛原创，要不要删掉换一条
5. **落脚到 Claude Code**：这条是第一条帖，就把账号定位隐隐锚到 vibe coder，合适吗？还是应该第一条先不锚定位？
6. **引导语 "冒个泡"** vs "扣 1"：我用的 "冒个泡"（§6.2 首推），但小红书冷启可能 "扣 1" 更能激活算法——你的 taste 怎么判？
7. **图片版权风险**：5 张原图贴上去有被判搬运的概率。接不接受？
