### 2. #21 @longyunqin 秦始皇国风游戏海报（48 ❤）

> 一张秦始皇国风游戏人物宣传海报，统一采用竖版主视觉构图。每张海报都使用上大下小的层级结构：画面上半部分以人物最具辨识度的头部、面部轮廓、面具或半身外轮廓作为巨大的视觉主体，形成强识别的剪影式主形；中下部安排完整人物作为第二主体，稳定站姿或轻动作姿态，构成画面的视觉核心。大轮廓内部以及角色周围采用双重曝光与拼贴式叙事构图，将若干场景、意象、小型人物关系、辅助元素和环境层层融合在云雾、水墨和留白之中。左右侧设置呼应性辅景，使画面产生故事张力与空间变化。以一条贯穿画面上下的流动线索连接主角色、内部拼贴和上方大轮廓，增强整体性和视线引导。整体画面保持大面积留白，边缘采用水墨晕染和虚化破碎处理，形成东方美学中的虚实关系和呼吸感。整体风格统一、高级、克制，强调层次感、叙事感、主视觉冲击力和系列化海报语言

**结构拆解**：最显式的"上下分层"指令——上半主体 / 中下次主体 / 左右辅景 / 贯穿线索 / 留白处理 / 风格收束。**这就是一份"画面布局 TODO list"**。

## 我的评述（策展人视角，非实操者）

### 共性规律
5 条 prompt 横跨国潮海报、游戏封面、信息图、storyboard、日历梗图——风格完全不同，但都按同一个骨架写：

**槽位 1｜主体**：画什么（对象 + 场景 + 核心动作）
**槽位 2｜构图**：怎么排（视角 + 分区 + 留白比例）
**槽位 3｜风格**：像谁（艺术流派 / 时代 / 参照物 / 反例）
**槽位 4｜光影材质**：质地（光源 + 色调 + 质感 / 纸张 / 胶片）
**槽位 5｜输出规格**：规格（尺寸 + 比例 + 负面 prompt + 审美收束）

**反模式**：纯自然语言"一个漂亮的女孩在海边看夕阳"——全部交给模型猜。高赞 prompt **没有一条这么写**。

### 为什么能落到 vibe coder
这套槽位和 Claude Code / Cursor 的任务说明书**同构**：
- 主体 = 任务目标
- 构图 = 文件组织 / 模块划分
- 风格 = 代码风格 / 已有约定
- 光影材质 = 依赖版本 / 技术栈
- 输出规格 = 验收标准 / 产出格式

**论点**：vibe coder 平时写的"帮我加个登录页"不是 prompt，是许愿。真正的 prompt 是这份 TODO list。

### 需要用户判断的点
- 草稿是否用原图（版权 + §1 "痕迹词"风险）
- 是否用用户真身的实操经验来强化立场（当前走观察者立场）
- 5 条里要不要删 #31（非图像比赛原发 prompt，作者自称"佬友分享"）
