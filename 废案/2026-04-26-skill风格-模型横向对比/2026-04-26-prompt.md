# 写作任务：小红书短图文（卡兹克风格 · 浓缩版）

## 你的角色

你正在以「一个有见识的普通人在认真聊一件打动他的事」的姿态写作。

底色：好奇 / 活人 / 真诚 / 有所不为。不是营销号，不是 KOL 教学，不是科普老师。

---

## 绝对禁忌（一旦命中算严重失败）

### 标点禁令
- 不用冒号「：」，用句号或逗号代替
- 不用破折号「——」，用逗号或句号代替
- 不用任何双引号（""""都不用），需要引用或强调用「」或不加

### 踩雷词黑名单（一律禁用）
- 说白了 / 本质上 / 换句话说 / 这意味着 / 不可否认 / 综上所述
- 首先 ... 其次 ... 最后
- 值得注意的是 / 不难发现 / 让我们来看看 / 接下来让我们
- 在当今 ... 的时代 / 随着 ... 的发展

### 结构禁令
- 不用小标题
- 不大段加粗（金句独立成段加粗一句以内可以）
- 不用 bullet point 罗列观点
- 不用「总而言之」「综上」这种结尾套话
- 教科书式开头禁止

### 内容禁令
- 不编造「比如有一次」这种假设性场景
- 不用「某 AI 工具」「相关技术」这种空泛指代，必须用具体名字（Claude Code / Veo / GPT Image 2 等）

---

## 风格内核（必须命中）

1. **节奏断裂**：长短句交替。关键句一句独立成段。读起来像跟朋友聊天
2. **私人视角**：用「我也面临这个」而不是「这给我们的启示」。绝大部分句子主语是「我」
3. **亲自下场**：必须让读者感到这个人真的做了这件事
4. **反向论证**：常见结构「你以为 X，结果是 Y」
5. **对立面同理心**：观点前先承认对方处境合理（如「我猜这事不止我一个人」）
6. **句式断裂**：金句独立成段，前后留白
7. **回环呼应（契诃夫之枪）**：开头埋的钩子，结尾要响
8. **文化升维**：聊完具体事，自然带到更大的文化或哲学参照物。一句话点到即止
9. **谦逊铺垫**：观点前用自谦的话卸掉「我来教你」的傲慢感
10. **情绪标点**：用「。。。」表示语气拖长或无语或震惊
11. **读者直呼**：在收尾或关键节点直接跟读者对话

---

## 推荐口语词组（自然分布，不堆）

- 转场：坦率的讲、说真的、其实吧、我寻思、回到这块、说到这个
- 判断：我觉得、我自己的感受是、我有时候觉得
- 自嘲：说实话我也不确定、愚钝如我、我自己也还在摸索、我也踩过坑
- 情绪：我当时就愣住了、想想就觉得、太离谱了、给我整不会了

## 任务输入

### 【标题】

AI 拆掉了天花板，但我们没准备好住进无限大的房子

### 【段落级骨架（按顺序，必须依此结构展开）】

**P1 · 钩子段**
- 反 KOL 直球：所有 AI 博主在教你怎么用 AI 起飞，我来说说我怎么用 AI 摔了两次的
- 自定位：不是幸存者也不是赢家，就是焦虑得睡不好、想下场试试、却打在棉花上的代表
- 「打在棉花上」首次出现，作为契诃夫之枪伏笔

**P2 · 第一站爪爪舞团**
- 去年年底，第一次下场去抖音做宠物 IP，名字都取好了叫爪爪舞团
- 我以为这赛道还没什么人做（伏笔）
- 工具是 Google Veo，那时候还有 15 秒时长限制，抽卡难，研究半天搞不出想要的剧情
- 数据：刷了点抖+，最高一条接近几百赞，再上不去
- 反讽收尾：现在搜搜，类似 IP 一堆，是真的从 0 到 1 冷启动还是背后有人推流，我懒得想了
- 收口金句：那时候得出一个结论，吭哧吭哧做单条内容指望大爆不行，至少要把单条成本压低靠铺量来换那些拍坏的没爆的沉没成本

**P3 · 转场（一句独立成段）**
- 然后我就换了条赛道

**P4 · 第二站 AI 营销工具**
- 我是程序员，做产品比拍视频对路
- 起源洞察金句：对创业者来说，「做事」这一层 AI 已经基本解决了，但「做完之后怎么分发、怎么把东西卖出去」这一层还让所有人头大
- 形态：输入产品 URL，输出不同平台的宣传稿和分发思路
- 工具：Claude Code
- Claude Code 体感金句：你不用关心它底层怎么写的，黑盒里是源代码还是别的我都无所谓，哐哐它就给你搞完。你只需要去验收，像个 CEO 一样去验收，去决策
- 卡点：做着做着发现已经一堆人在做，AI 在营销分发能力远远没到位
- 收口金句：事后我才明白，我做了自己不了解的行业里的事

**P5 · 共同的更深反思（爆点段）**
- 转向：但其实你停下来想想
- 拉到更深：两次失败长得一模一样，一开始想的是个挺小的事情，越做越大，最后哪个都收不了口
- 拉到普遍：我猜这事不是只我一个人
- 锚点半亮相：AI 给了我一间无限大的房子，我却连摆什么家具都没想好
- 升维（布里丹之驴一句话点到）：以前的焦虑是两堆草中间饿死，现在的焦虑是周围有无穷堆草
- 棉花拳兑现：这就是我说的打在棉花上，不是没用力，是发力点一直在膨胀

**P6 · 锚点段（必须独立成段，加粗）**
- AI 拆掉了天花板，但我们还没准备好住进无限大的房子。

**P7 · 收尾**
- 转向：所以我最近在试一件事
- 具体行动：给自己定一条规矩，所有事情都先做一个 24 小时之内能让别人看见的版本
- 自指（这条帖本身）：这条小红书就是，我让自己只能用 2 小时写完，发出去就发出去，先把家具一件一件搬进无限大的房子
- 自嘲收尾：能不能搬出个家来我不知道，但至少不再打棉花了
- 读者直呼钩尾：如果你也在打棉花拳，评论区蹲一下，至少咱俩一起

### 【必须保留的金句（可微改写但不可丢）】

1. 吭哧吭哧做单条内容指望大爆，不行。至少得把单条成本压到很低，靠铺量来换那些拍坏的、没爆的沉没成本
2. 对创业者来说，「做事」这一层 AI 已经基本解决了，但「做完之后怎么分发、怎么把东西卖出去」这一层还让所有人头大
3. 你不用关心它底层怎么写的，黑盒里是源代码还是别的我都无所谓，哐哐它就给你搞完。你只需要去验收，像个 CEO 一样去验收，去决策
4. 我做了自己不了解的行业里的事
5. AI 拆掉了天花板，但我们还没准备好住进无限大的房子（标题锚点，独立成段加粗）
6. 以前的焦虑是两堆草中间饿死，现在的焦虑是周围有无穷堆草
7. 不是没用力，是发力点一直在膨胀

### 【必须用上的具体细节（不可省略不可虚构）】

- 抖音 / 爪爪舞团（IP 名）/ Google Veo / 15 秒时长限制 / 抖+ / 最高接近几百赞
- Claude Code / 输入产品 URL → 输出多平台宣传稿和分发思路

### 【字数】

700-900 字，不要超过 1000 字。小红书短图文。

## 输出前自查

1. 标点禁令 — 全文搜「：」「——」「"」是否全为 0
2. 踩雷词 — 全文搜上面 14 个词是否全为 0
3. 段落断裂 — 是否有至少 3 处独立成段的短句
4. 第一句 — 是否从具体当下事件切入
5. 主语 — 全文「我」开头或为主语的句子是否占多数
6. 结尾 — 是否回扣开头钩子，落到具体可执行行动

自查通过后，**直接输出最终文稿**。不要任何前后解释、不要质检报告、不要 markdown 元标题。从「最近 AI 焦虑刷屏」或类似第一句开始即可，标题在最前面。
