# DeepSeek V4 Flash · 原 SKILL 直喂版 v1 · 留档

## 成稿全文（保持原样，不修复）

> 见 [2026-04-26-deepseek-skill-flash-v1-raw.md](2026-04-26-deepseek-skill-flash-v1-raw.md)

正文从下面开始：

```
AI 拆掉了天花板，但我们没准备好住进无限大的房子

<br>

所有 AI 博主都在教你用 AI 起飞，我今天说说我怎么用 AI 摔的两次。

我不是幸存者，也不是什么赢家。

我是一个焦虑得睡不好、想下场试试、却反复打在棉花上的人。

你看，这就是我说的「打在棉花上」，不是没用力，是发力点一直在膨胀。

---

第一次下场是去年年底。

我去抖音做宠物 IP，名字叫爪爪舞团。我以为这赛道还没什么人做。

工具是 Google Veo，当时 15 秒时长限制，抽卡难，研究半天搞不出剧情。

刷了点抖+，最高接近几百赞，再上不去。

现在搜搜类似 IP，一堆。是从 0 到 1 还是有人推流，懒得想了。

收口：吭哧吭哧做单条内容指望大爆不行，至少要把单条成本压低，靠铺量来换那些拍坏没爆的沉没成本。

---

然后我就换了条赛道。

<br>

我是程序员，做产品比拍视频对路。

起源洞察：对创业者来说，做事这一层 AI 已经基本解决了，但做完之后怎么分发、怎么把东西卖出去，这一层还让所有人头大。

形态：输入产品 URL，输出不同平台的宣传稿和分发思路。

工具：Claude Code。

Claude Code 体感很离谱。你不用关心它底层怎么写的，黑盒里是源代码还是别的我都无所谓，哐哐它就给你搞完。你只需要去验收，像个 CEO 一样去验收，去决策。

卡点：做着做着发现一堆人已经在做，AI 在营销分发这块能力远远没到位。

收口：事后我才明白，我做了自己不了解的行业里的事。

---

但其实你停下来想想，两次失败长得一模一样。

一开始想的是个挺小的事情，越做越大，最后哪个都收不了口。

我猜这事不是只我一个人。

AI 给了我一间无限大的房子，我却连摆什么家具都没想好。

以前的焦虑是布里丹之驴，两堆草中间饿死。现在的焦虑是周围有无穷堆草，你不知道从哪口开始啃。

这就是我说的打在棉花上。不是没用力，是发力点一直在膨胀。

---

AI 拆掉了天花板，但我们还没准备好住进无限大的房子。

<br>

所以我最近在试一件事。

给自己定一条规矩，所有事情都先做一个 24 小时之内能让别人看见的版本。

这条小红书就是。我让自己只能用 2 小时写完，发出去就发出去，先把家具一件一件搬进无限大的房子。

能不能搬出个家来我不知道，但至少不再打棉花了。

如果你也在打棉花拳，评论区蹲一下，至少咱俩一起。
```

## 关键失败点诊断

### 主要失败 · 把骨架描述的 label 字面复述进正文

我的 [task-part](2026-04-26-prompt-skill-task.md) 里用了如下写法：
```
- 收口（用户原话凝练，措辞由你判断）：吭哧吭哧做单条内容…
- 起源洞察（用户原话凝练）：对创业者来说…
- 形态：输入产品 URL…
- 工具：Claude Code
- Claude Code 体感（用户原话凝练）：你不用关心…
- 卡点：做着做着…
- 收口（用户原话凝练）：事后我才明白…
```

DeepSeek V4 Flash 把这些 **写给它看的"组织标签"** 当成 **要复述到文章里的"正文标签"**，于是文章变成了「收口：xxx 起源洞察：xxx 形态：xxx 工具：xxx 卡点：xxx 收口：xxx」这种类似 PPT bullet point 的结构。这是显著的指令理解失败。

Claude Opus 4.7 看同样的骨架描述，知道这些 label 是「内部组织参考」而非「正文标签」，自然把它们融入行文。

**这是 Claude 和 DeepSeek 在指令理解层面的真实差异。**

### 次要失败 · 钩子段提前用掉爆点

P1 钩子段（"我是一个焦虑得睡不好…的人"之后）紧接着第 11 行：

> 你看，这就是我说的「打在棉花上」，不是没用力，是发力点一直在膨胀。

这一句**应当是 P5 爆点段最后的兑现**，DeepSeek 在 P1 就提前用掉了。然后 P5 第 59 行又重复一次，造成全文结构上的双重重复。这破坏了契诃夫之枪的"埋 → 响"节奏。

### 责任分担

- 「label 复述」问题：**主要是 DeepSeek 指令理解能力**。Claude 在同样输入下没犯这个错。但我的 task-part.md 写法（用「收口：xxx」这种字面格式）确实给了 DeepSeek 不好的 cue。理论上可以改写 task-part 避开这种格式，再跑一次看 DeepSeek 是否改善
- 「钩子提前用爆点」：**纯 DeepSeek 自己的判断失误**。骨架里 P1 和 P5 是分开写的
