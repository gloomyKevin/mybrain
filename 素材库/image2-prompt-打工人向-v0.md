# Image 2 生图比赛 · 打工人向 prompt 合集(v0)

## 筛选原则

豆老师拜托了账号定位是**普通打工人的 AI 分享号**,读者是想用 AI 的普通打工人。
筛 prompt 的标准(对照 `运营/豆老师拜托了-人设档.md`):

- **情感锚强**:读者看到能联想到自己生活场景(老家 / 节日 / 朋友圈 / 微信斗图)
- **模板化可改**:一条 prompt 换几个关键词就能衍生多张
- **出图稳定**:原帖有多人仿做成功的证据,不是个例
- **不要专业向**:游戏封面、storyboard、写真、NSFW 全排除

前 200 楼筛出 8 条,分三档。

### 1. 城市宣传海报 · S 型双重曝光

**原作者**:@alidrzml(花、小福狸),linux.do #8,反应 heart×86, +1×22, clap×3

**原 prompt**:

```
一张充满新春喜庆氛围但不失高雅格调的 2026 城市宣传海报。
双重曝光,构图延续了S型的流动感;
在纯白的纹理背景右下角,一个身穿中国传统服饰的微缩人物正在挥舞着一条长长的红色丝绸舞带,这条红绸在空中舞动,不仅展现出丝绸的柔顺质感,更在向左上方飘动的过程中,奇幻地变形成了一条壮丽的山脉河流。
在这条"河流"中,叠加了一个有山有海河的上海城市手绘图,国潮,景色尽在眼底,壮阔雄伟,令人震撼。
上海的地标建筑(东方明珠广播电视塔,外滩建筑群,黄浦江江, 豫园,龙华寺,佘山)。

文字排版优美,大方,字迹清晰完整,尺寸9:16。
```

**关键可换槽位**:
- **城市名**(上海 → 杭州 / 北京 / 深圳 / 成都 / 武汉 / 南京 / 苏州 / 西安 / 任何老家县城)
- **地标建筑列表**(换成该城市的 4-6 个地标)
- **主题 slogan**("经济中心,魅力魔都" → 各城市对应)
- **季节 / 节日**("SPRING 2026" → 中秋 2026 / 国庆 2026 / 任何节日)
- **丝绸颜色**(红 → 墨绿 / 金色 / 靛蓝,对应不同主题气质)

**打工人用场景**:
- 发朋友圈(老家海报 / 工作城市海报,情感锚极强)
- 家族群 / 发给父母(给老家做一张,亲戚都会转)
- 电脑壁纸 / 手机锁屏
- 结婚请柬背景 / 节日贺卡

**为什么最强**:原帖出现连锁仿做效应(上海 → 杭州 → 桂林 → 老家),证明模板极度稳定。打工人都有"一个老家 + 一个漂的城市",情感入口最宽。

### 4. 轮廓宇宙叙事海报 · 万能 IP 模板

**原作者**:#25 @yahuhu(凡人修仙传,12 赞) + #169 @Misunderstood(通用无限制版,6 赞) + #201 @XinLeo(历史人物毛泽东版)

**推荐通用版 prompt**(#169 版,最灵活):

```
请根据【主题:xxx】自动生成一张高审美的"轮廓宇宙 / 收藏版叙事海报"风格作品。不要将画面局限于固定器物或常见容器,不要优先默认瓶子、沙漏、玻璃罩、怀表之类的常规载体,而是由 AI 根据主题自行判断并选择一个最契合、最有象征意义、轮廓最强、最适合承载完整叙事世界的主轮廓载体。这个主轮廓可以是器物、建筑、门、塔、拱门、穹顶、楼梯井、长廊、雕像、侧脸、眼睛、手掌、头骨、羽翼、面具、镜面、王座、圆环、裂缝、光幕、阴影、几何结构、空间切面、舞台框景、抽象符号或其他更有创意与主题代表性的视觉轮廓。

画面的核心不是简单把世界装进某个物体里,而是让完整的主题世界自然生长在这个主轮廓之中、之内、之上、之边界里或与其结构融为一体。主轮廓必须清晰、优雅、有辨识度。轮廓内部或边界中需要自动生成与主题强绑定的完整叙事世界,包括最能代表主题的标志性场景、核心建筑或空间结构、象征符号与隐喻元素、角色关系或文明痕迹、远景中景近景的空间递进、具有命运感和情绪张力的氛围层次。

整体构图需要具有强烈的收藏版海报气质与高级设计感,大结构稳定,主轮廓强烈明确,内部世界具有纵深、秩序和呼吸感。风格融合收藏版电影海报构图、高级叙事型视觉设计、梦幻水彩质感与纸张印刷品气质,强调纸张颗粒感、边缘飞白、水彩刷痕、轻微晕染、大面积留白与克制版式。

色彩由 AI 根据主题自动判断并匹配最合适的高级配色方案,但必须保持统一、克制、耐看、低饱和、高级。不要普通背景拼接,不要生硬裁切,不要模板化奇幻素材,不要游戏宣传图感,不要过度卡通化。
```

**关键可换槽位**:
- **【主题】**:几乎任何东西都能填
  - 动漫 IP(凡人修仙传 / 原神 / 一人之下 / 火影忍者)
  - 电影(哈利波特 / 星战 / 指环王 / 三体)
  - 小说(红楼梦 / 三体 / 诡秘之主)
  - 历史人物(李白 / 秦始皇 / 毛泽东 / 拿破仑)
  - 游戏(塞尔达 / 黑神话悟空 / 艾尔登法环)
  - 城市 / 地理(江南 / 北境 / 你的老家)

**打工人用场景**:
- 喜欢某个 IP → 做一张自己用的壁纸 / 头像背景
- 给朋友送生日图(知道朋友喜欢什么 IP 就生成什么)
- 小红书 / 书影音笔记的配图

**为什么强**:这条是整个赛道**最通用的模板**,改一个【主题】关键词就能跑不同风格,出的图都自带"高级收藏版海报"气质。

**原作者**:@heng91(白奈),linux.do #5,反应 heart×21, +1×4

```
高仿真纸质老黄历单页设计,日期2026年4月23日,农历三月初七,宜「重构代码」「周四上线」,忌「古法编程」「删库」,今日幸运词「AI不降智」,呈现程序员与AI协作元素,老式排版加木刻字体
```

**打工人改造版**:

```
高仿真纸质老黄历单页设计,日期 [今天日期],农历 [今天农历],
宜「[你想干的两件事,比如"摸鱼 3 小时""周四发工资到账"]」,
忌「[你想躲的两件事,比如"周一早会""老板 @ 我""需求变更"]」,

呈现打工人日常元素(电脑、奶茶、工牌、工位),老式排版加木刻字体。
```

**关键可换槽位**:
- **宜 / 忌**:完全自定义,反映当天打工心情
- **幸运词**:自编,要带打工人梗
- **元素**:可以加外卖盒子、敷衍点头的表情、红牛罐

**打工人用场景**:
- 每周一 / 周四发朋友圈
- 群聊当日历发
- 打印出来贴工位

**为什么强**:模板极轻(就几个关键词),生成速度快,梗可以按当天情绪现编。

### 8. 双重曝光人生侧脸轮廓 · 送礼专用

**原作者**:@Fluence,linux.do #80,反应 heart×9, +1×1

**原 prompt**:

```
一张高级双重曝光艺术海报,以老年人的侧脸轮廓作为主体外形,轮廓内部清晰而诗意地容纳他一生的重要阶段:童年奔跑、少年读书、青年追梦、成年工作与家庭、中年沉思、老年回望。所有阶段都应看出是同一个人的不同年龄,面部特征与气质保持一致。内部场景随着年龄变化呈现春夏秋冬与清晨到夜晚的光线过渡,象征生命时间线。整体构图克制、留白高级,不做杂乱拼贴,而是层次分明、过渡自然、具有文学性和哲思感。色调以黑白灰、暖金、雾蓝或褪色胶片色为主,充满记忆感、时间感、命运感。画面像国际电影节海报、文学封面或美术馆展览主视觉,优雅、安静、深刻、余味悠长。
```

**关键可换槽位**:
- **年龄段描述**:童年 → 少年 → ... 这几段可以换成具体的人生事件("高考那年的夏天""第一次上班""结婚那天")
- **性别**:老年人 → 老年妇女 / 中年男人(看送给谁)
- **职业线索**:可在场景里埋(老师的讲台、医生的白大褂、司机的方向盘)

**打工人用场景**:
- 父母生日礼物(打印出来送)
- 长辈葬礼追思(慎用,情绪重)
- 自己生日自我反思(30 岁)

**为什么是小众**:情绪强但场景不频繁,一年用不了几次。收藏价值高,但不适合主推。
